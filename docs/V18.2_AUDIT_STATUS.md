## Audit 1 — robustesse du socle
Validé : dépendances, compilation, lint ciblé, tests, quotas et garde-fous de provenance.

## Audit 2 — API réelles
Validé : OpenFIGI, Marketstack, Alpha Vantage, Finnhub, FRED et EIA ont chacun passé leur smoke réel. Alpha Vantage est limité au fallback OHLCV global.

## Audit 3 — pipeline complet
Premier run complet : échec uniquement sur `wave_01_ohlcv_success_pct` (81,5 % pour les Actions, 99,02 % pour les ETF). Cause dominante : rate-limit Yahoo et nombreux tickers européens sans suffixe.

Corrections du second passage :
- les tickers européens nus ne sont plus envoyés directement à Yahoo ;
- OpenFIGI reste prioritaire pour la réparation de symbole ;
- un suffixe Yahoo de marché domestique peut être formé sans appel API lorsque le ticker est nu et le préfixe ISIN est pris en charge ;
- après les retries bulk, Yahoo passe par une récupération en petits lots, sans multithreading et avec cooldown ;
- les quotas Marketstack et Alpha Vantage restent inchangés et conservateurs ;
- le seuil OHLCV de 90 % n'est pas abaissé.

Statut : second run complet déclenché par ce commit. `main` reste inchangée.

Non commencé tant que l'audit 3 complet n'est pas vert.
