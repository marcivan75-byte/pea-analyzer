# V21.1 TCT EXPLOSIF — Spécification

## 1. Objet

`V21.1_TCT_EXPLOSIF` est un module Actions PEA séparé du score CT général. Il recherche des configurations susceptibles de produire une hausse rapide dans les 1 à 20 séances, sans modifier les pondérations de production V21.0.

Le module reste `RESEARCH_ONLY` et `SHADOW` jusqu'à validation empirique point-in-time. Un score TCT n'est pas une probabilité. La probabilité de hausse d'au moins 15 % en 20 séances n'est exposée comme probabilité calibrée qu'après validation chronologique hors échantillon avec un nombre suffisant d'événements positifs.

## 2. Cible mesurable

Événement principal : maximum futur >= +15 % dans les 20 séances suivant le signal.

Entrée de backtest : **open de la séance suivante**, jamais le close ayant servi au calcul du signal.

Événement contrôlé : l'objectif +15 % est atteint avec une excursion adverse maximale jusqu'au premier hit >= -12 %.

Le backtest doit publier au minimum : précision, rappel, taux de base, lift, précision Top-K, Brier score lorsqu'une probabilité est calibrée, rendement futur maximum moyen, MAE et proxy de profit factor.

## 3. Architecture active

| Pilier | Poids V21.1 | Rôle |
|---|---:|---|
| Impulsion technique | 30 % | Breakout, MM20/50/200, reversal, MACD, RSI, stochastique, force relative, gap |
| Catalyseur événementiel | 20 % | M&A confirmé, résultats, guidance, contrats, réglementaire, FDA/EMA |
| Volume / squeeze | 15 % | RVOL, short float, positions courtes publiques, gap, days-to-cover |
| News / secteur | 12 % | News instrument, news secteur, momentum secteur |
| Valorisation relative | 8 % | Décote sectorielle, PEG, FCF yield, EV/EBITDA |
| Révisions analystes | 6 % | Momentum analyste, delta consensus, upgrades, révisions pondérées |
| Risque / liquidité | 5 % | Liquidité, drawdown, volatilité |
| Corporate / insider | 2 % | Buyback/corporate actif ; insider calculé en shadow avant validation |
| Macro / rotation | 2 % | Top-down et régime de sentiment |

Les piliers `social_sentiment` et `microstructure_orderflow` restent en shadow, sans poids positif actif, jusqu'à disponibilité d'une donnée fiable et backtestable.

## 4. Synergies

Le score ajoute des bonus plafonnés afin de privilégier la confluence plutôt qu'un signal unique :

- impulsion technique forte + volume/squeeze fort ;
- catalyseur fort + news corroborantes ;
- short float élevé + RVOL >= 2 + breakout 20 jours.

Le bonus total est plafonné à 8 points.

## 5. Garde-fous

- univers canonique courant : 1 429 Actions PEA ;
- renormalisation uniquement sur critères observés, jamais de valeur neutre 50 inventée ;
- identité ticker minimale 92 % ;
- éligibilité PEA `HIGH` exigée lorsque le champ est disponible ;
- couverture minimale 55 %, 62 % pour Satellite et 72 % pour Coeur ;
- liquidité sous le 5e percentile : rejet ; sous le 10e percentile : pas de Coeur ;
- profit warning : malus fort ;
- contexte top-down `BLOCK_BUY` / `REVIEW_ONLY` : malus ;
- gap > 15 % : pénalité anti-chasse ;
- drawdown 1 an < -40 % : pénalité ;
- rumeur M&A seule plafonnée : elle ne peut pas créer un `COEUR_TCT_EXPLOSIF` ;
- un `COEUR_TCT_EXPLOSIF` exige soit un catalyseur >= 65, soit la combinaison technique >= 75 et volume/squeeze >= 75.

Le gate AUM n'est pas appliqué aux actions. Les contrôles pertinents sont liquidité, identité, éligibilité, volatilité/drawdown et qualité de données.

## 6. Données nouvelles

L'enrichissement technique quotidien ajoute notamment :

- MM20, MM50, MM200 et alignement ;
- RSI14 ;
- MACD, signal et histogramme ;
- ATR14 ;
- largeur Bollinger ;
- volume moyen 20 jours et RVOL ;
- breakout 20 jours ;
- gap d'ouverture ;
- performances 1/5/20 jours ;
- stochastique K/D et croisement haussier.

Les champs V21.0 déjà disponibles sont réutilisés : valorisation, consensus, révisions, earnings, news, buyback, M&A, top-down, short float, insiders et Smart Money.

## 7. Hiérarchie de sources

### Preuve primaire

Émetteur / relations investisseurs, AMF/BDIF et open data réglementaire, avis émetteur Euronext.

### Sources secondaires / enrichissement

Finnhub et Yahoo Finance pour enrichissement ciblé, sous contrôle de couverture et de provenance.

### Découverte uniquement

GDELT et données sociales. Un article agrégé ou une rumeur ne constitue jamais à lui seul une preuve suffisante pour un signal Coeur.

Les positions courtes AMF publiées sont utilisées comme signal public réglementaire ; elles ne sont pas assimilées au short interest total du titre.

La microstructure temps réel / carnet d'ordres n'est pas activée à partir d'un scraping gratuit fragile. Elle nécessite une source de données adaptée et reproductible.

## 8. Probabilité et calibration

`tct_probability_20d_calibrated` reste vide tant que la calibration n'est pas validée.

La calibration actuelle est monotone par bins avec validation chronologique holdout. Elle exige au minimum 75 événements positifs dans l'échantillon d'apprentissage. Une probabilité calibrée inférieure à 65 % rétrograde un Coeur en Satellite ; ce gate n'est actif que lorsque la probabilité existe réellement.

Avant passage en production, la validation devra être complétée par des fenêtres rolling/purged walk-forward afin de réduire le risque de surapprentissage et de fuite temporelle.

## 9. Backtests 12 / 18 / 36 mois

Le runner `scripts/backtest_tct_explosif_v211.py` attend :

1. des scores historiques point-in-time par date/instrument ;
2. un historique OHLC quotidien point-in-time ;
3. le rapprochement score/date avec l'entrée next-open ;
4. les métriques par fenêtres 12, 18 et 36 mois ;
5. la calibration chronologique si le nombre d'événements est suffisant.

Aucune performance cible (65–75 % ou autre) ne doit être annoncée avant ces résultats hors échantillon.

## 10. Sorties quotidiennes

- `outputs/V21.1_TCT_EXPLOSIF_1429.csv` : univers complet et décomposition des scores ;
- `outputs/V21.1_TCT_EXPLOSIF_TOP20.csv` : Top 20 du jour ;
- `outputs/audit/V21.1_TCT_EXPLOSIF_AUDIT.json` : audit du run ;
- `outputs/audit/V21.1_TCT_TECHNICAL_ENRICHMENT.json` : audit de l'enrichissement technique.

Décisions possibles :

- `COEUR_TCT_EXPLOSIF` ;
- `SATELLITE_TCT_EXPLOSIF` ;
- `SCAN_TCT_EXPLOSIF` ;
- `REJECT_TCT`.

## 11. Workflow

Le workflow `tct-explosif-v21-1.yml` est prévu les jours ouvrés à 18 h heure de Paris. Deux cron UTC sont déclarés et un gate timezone Paris ne laisse exécuter que celui correspondant réellement à 18 h, afin de couvrir heure d'été et heure d'hiver.

Le workflow :

1. exécute les tests TCT ;
2. reconstruit/enrichit la base V21 Actions ;
3. enrichit les signaux techniques TCT ;
4. calcule le score et le Top 20 ;
5. publie les sorties sous forme d'artifact GitHub.

Aucun ordre réel n'est créé. Les alertes réellement intraday ne font pas partie de ce workflow quotidien et devront être traitées dans une couche séparée avec une fréquence et des données compatibles.

## 12. Critères de passage de SHADOW à actif

Le passage à un usage décisionnel renforcé nécessite simultanément :

- historique point-in-time suffisant et absence de fuite temporelle ;
- stabilité des résultats sur 12/18/36 mois et plusieurs régimes de marché ;
- lift significatif sur le taux de base ;
- précision Top 20 robuste ;
- calibration acceptable ;
- drawdown/MAE compatible avec l'objectif de risque ;
- stabilité des pondérations en sensibilité ;
- sources catalyseurs suffisamment corroborées ;
- audit de non-régression du moteur V21.0 ;
- maintien de `NO_LIVE_EXECUTION` jusqu'à décision explicite ultérieure.
