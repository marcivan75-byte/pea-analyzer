## Limites qui nécessitent obligatoirement un futur run manuel

Un audit statique peut prouver que la source est correctement câblée, que ses champs sont propagés et que les garde-fous sont présents. Il ne peut pas prouver, sans requête réelle :

- qu'une clé API est encore valide au moment du run ;
- qu'un endpoint free-tier expose effectivement chaque champ pour chaque instrument ;
- qu'un site public n'a pas modifié son HTML, ses protections ou ses conditions d'accès ;
- le taux de couverture réel obtenu sur les 1 429 Actions / 102 ETF ;
- le gain réel de couverture et l'impact sur les décisions.

Ces éléments restent donc explicitement marqués `NOT_RUN_BY_USER_REQUEST` et devront être certifiés lors du prochain lancement manuel autorisé.
