# Spécification V18.2

## Objectifs

- maximiser le nombre de champs observés ;
- privilégier les collectes bulk ;
- tirer plusieurs dizaines de critères d'une seule collecte OHLCV ;
- économiser les quotas API ;
- reprendre après incident ;
- mesurer exactement le gain de couverture par vague.

## Indicateurs calculés depuis OHLCV

Performances 1m/3m/6m/1a/3a/5a, MM20/50/100/200, RSI14,
MACD, ATR14, Bollinger, RVOL20, volatilité 20/60 jours,
drawdown maximal, force relative et retournement positif.

## Consensus, objectifs et Comité — V18.2.1

Après WAVE_05, WAVE_09 calcule un historique décisionnel autonome : potentiel vers
l'objectif, révisions d'objectif S-1/1m/3m/12m en valeur et en pourcentage,
changements de consensus, breadth des révisions, pondération broker, confiance
multi-source et accélération des objectifs.

Le score `analyst_momentum_score` est conservé séparément et pèse 15 % dans
`committee_score_with_analyst_momentum`; `score_brut` n'est jamais écrasé.
Une baisse d'objectif d'au moins 10 % sur un mois peut imposer
`BLOCK_NEW_BUY_REVIEW`. L'exécution reste SHADOW_BLOCKED.

Les comptes d'analystes de Yahoo, Finnhub, MarketBeat ou d'autres fournisseurs
ne sont jamais additionnés. Une source canonique fournit le nombre d'analystes ;
les autres sources servent à confirmer ou mesurer une divergence.

Voir `config/V18.2_CONSENSUS_PIPELINE.json`,
`config/V18.2_CONSENSUS_DECISION_FIELDS.csv` et
`docs/V18.2_COMMITTEE_DECISION.md`.
