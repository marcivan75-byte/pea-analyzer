# Gold V1 — politique décisionnelle shadow

Le module OR V1 est **décisionnel immédiatement** en mode `SHADOW / RESEARCH_ONLY`.

Le statut shadow signifie que le module peut :

- calculer GOLD_SCORE_MT et GOLD_SCORE_CT ;
- produire ENTRY_SCORE ;
- classer le régime OR ;
- appliquer les hard gates ;
- publier une décision de recherche (achat, renforcement, surveillance, allègement, éviter) ;
- alimenter le comité global.

Le statut shadow signifie également que le module ne peut pas :

- déclencher un ordre réel ;
- modifier automatiquement une allocation réelle ;
- considérer ses pondérations V1 comme statistiquement optimales avant backtest.

Le backtest PIT / walk-forward / out-of-sample reste obligatoire pour valider les pondérations et toute future promotion hors shadow, mais **il ne bloque pas la production de décisions de recherche**.

Les seuls blocages décisionnels restent les hard gates opérationnels (qualité de données, anti-look-ahead, etc.).

T1/T2 restent exclus du module OR et réservés aux Actions TCT.
