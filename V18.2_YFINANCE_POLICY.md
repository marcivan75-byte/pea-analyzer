# Politique Yahoo Finance / yfinance

`yfinance` est le premier filet large, sans clé API.

Principes :
- collecte par lots ;
- cache Parquet ;
- échec d'un ticker sans arrêt du run ;
- pas de garantie qu'un champ fondamental soit toujours exposé ;
- toute absence reste `NON_OBSERVE` ;
- contrôle par Marketstack, Alpha Vantage ou source officielle sur les dossiers prioritaires.
